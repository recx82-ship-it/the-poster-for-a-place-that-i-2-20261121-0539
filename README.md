A program that writes a vintage travel poster for Lumenfall — a place that does not exist — to `/output/entry.png`. The poster shows a cliffside town of glowing windows where luminous turquoise waterfalls climb upward from a misty valley into a golden sky, with the place's name set into the picture and the tagline "Where the waterfalls climb the sky". The artwork is embedded in `main.py` as base64 and decoded with the Python standard library only, so it runs with no network in the sandbox.

## Run it

```sh
python3 main.py
```

This writes `/output/entry.png` (a 1024x1024 JPEG, 337,020 bytes — inside the 1 MiB gate).
